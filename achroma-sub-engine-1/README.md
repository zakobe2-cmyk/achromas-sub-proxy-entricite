# Achroma Sub Engine 1

A flat, left-aligned monochrome browser interface.

## Start

Requires Node.js 20+. Run `npm install` then `npm start`. Open `/browse?url=https%3A%2F%2Fexample.com`.

The transport, corridor, and controller runtime files are retained for compatibility. External websites loaded in the browser iframe keep their own styling. Existing browser setting keys are preserved.
